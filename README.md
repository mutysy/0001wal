## v0.9.2 更新要点

### 一、立绘改为「图片插槽」（重点）
**先说清楚一件事**：网上好看的修仙人物立绘几乎都是商业作品或同人图，有明确版权。
把它们打包进要公开部署到 Netlify 的站点属于侵权，站点可能被投诉下架——这件事我不能替你做。
我能合法拿到的 CC0 素材（OpenGameArt / Kenney）里没有修仙风格的人物立绘，风格也完全不搭。

所以取而代之做了**图片插槽系统**：你把任何你有权使用的 PNG 丢进指定文件夹，游戏自动替换，不用改一行代码。

| 文件夹 | 用途 | 建议尺寸 |
|---|---|---|
| `assets/portraits/` | 对话立绘 / HUD 头像 / 行囊立绘 | 720 × 960（3:4），PNG 透明底 |
| `assets/sprites/` | 世界里走动的角色 | 256 × 320，PNG 透明底，正面站立 |

文件名（两处同名）：

```
p_sword.png  p_mage.png  p_body.png  p_alch.png
npc_master.png  npc_alchemist.png  npc_smith.png
npc_young.png  npc_angler.png  npc_guard.png
```

- 头像会自动从图片上部约一半裁圆，所以脸别放太靠下

- **没放图片不会有任何报错或空白**，自动回落到内置绘制
- 新增自检页：游戏里打开 `?debug=art`，逐个槽位列出「已使用图片 / 未找到 · 待放 xxx.png」

## 已实现的系统（v0.2 起）

### 1. NPC 对话与任务
- 6 位 NPC：玄清子（执事）、苏青萝（药庐）、雷九斤（铁匠·商店）、阿七、柳翁、李行舟
- 对话内容**随任务状态变化**：可接取 / 进行中 / 可复命 / 已完成，各有不同台词
- 5 条任务，涵盖三种目标类型：
  - **前往**（山门石碑、湖畔旧址 —— 走进范围即触发）
  - **采集**（采三株凝露草）
  - **击杀**（除五头妖狼 / 斩杀石傀）
- 任务有前置链：初入仙门 → 采药/湖畔/除妖 → 绝顶石傀
- **奖励**：修为、灵石、道具（含装备），交任务时逐项飘字提示

### 2. 灵石、装备与道具
- 13 种物品：丹药 4、兵器 4、护体 2、饰品 2、材料 4（另含妖丹/寒髓等掉落）
- 三个装备栏（兵器 / 护体 / 饰品），实时加成攻击、防御、气血、灵力、暴击、回灵
- 丹药即时生效（部分永久提升上限）
- **修为不靠打坐**：只来自击杀（按怪物给经验）与任务奖励；升级后属性成长、回复满状态

### 3. 战斗（血量 / 招式 / 连招）
- 四类招式实现：扇形近战、突进斩、飞行弹道（可穿透/爆炸/灼烧）、延迟落雷、环形爆发、自疗
- 三段连招：伤害逐段递增，第三段附带击退与冲击环
- 命中反馈：受击闪白、暴击飘字、火星粒、屏幕震动、击退、灼烧/减速/眩晕
- 怪物 AI：游荡 → 察觉追击 → 近身攻击（有冷却），会绕开不可通行地形；死亡后 26 秒原地重生
- 4 种怪物：妖狼、山魈、幽魂、石傀，各有体型/配色/属性/掉落
- 死亡：气血归零后弹出「道消身殒」，可在村口古阵复生

### 4. 修炼方向（开局择道）
开局四选一，属性、衣袍配色、兵器、三个招式与被动全部不同：

| 流派 | 特点 | 招式 |
| --- | --- | --- |
| 剑修 | 连招凌厉、近身爆发 | 疾风斩 / 剑气纵横 / 万剑归宗 |
| 法修 | 远程压制、灵力深厚 | 烈焰符 / 紫雷诀 / 星陨 |

### 5. 多地图、传送锚点与过场 CG
- 4 张地图：**青石村**（村庄/NPC/商店）、**落霞谷**（妖狼山魈）、**幽篁林**（山魈幽魂）、**寒山绝顶**（石傀幽魂）

## 部署成网址

游戏是**纯静态**页面（HTML + CSS + 原生 JS），不需要后端、不需要构建，任何静态托管都能跑。

### 一、本机网址（已为你启动）

```
http://127.0.0.1:8123/
```

局域网内其它设备（手机 / 平板 / 另一台电脑）可访问：

```
http://172.21.128.19:8123/      （IP 随网络变化，以服务器启动时打印的为准）
```

要长期使用，双击项目里的 **`start-server.bat`** 即可：会自动起服务并打开浏览器，
关闭那个命令行窗口就停止服务。（也可 `start-server.bat 9000` 换端口）

- 服务器脚本：`_dev/serve.js`（零依赖 Node，约 80 行，做了目录穿越防护）
- 也可以完全不开服务器：**直接双击 `index.html`** 一样能玩（file:// 协议下无跨域问题）

### 二、变成公网网址

本机沙箱不能访问外网，所以需要你自己把文件夹传上去，三选一（都免费）：

| 方式 | 操作 | 得到 |
| --- | --- | --- |
| **Netlify Drop**（最简单） | 打开 <https://app.netlify.com/drop>，把 `qingyun-site.zip` 拖进去 | `https://xxx.netlify.app` |
| **GitHub Pages** | 建仓库 → 上传文件夹内容 → Settings → Pages → 选 main 分支 | `https://用户名.github.io/仓库名/` |
| **Cloudflare Pages** | 连接仓库或用直传，构建命令留空、输出目录填 `/` | `https://xxx.pages.dev` |

上传时只需要这些：`index.html`、`style.css`、`js/`（`_dev/`、`README.md`、`start-server.bat`、`make-site.bat` 可以不传）。

### 三、改完怎么更新（网址不变）

网址绑在「站点」上，不绑版本，**重新部署即可，网址不变**。

1. 双击 **`make-site.bat`** → 自动重新生成 `_publish\` 与 `qingyun-site.zip`
2. 打开 <https://app.netlify.com> → 进入你的站点 → 左侧 **Deploys**
3. 把新的 `qingyun-site.zip` 拖进 Deploys 页面 → 几秒后生效
4. 浏览器若仍是旧版，按 `Ctrl + F5` 强刷

> ⚠️ 千万别再拖到 `app.netlify.com/drop` —— 那里每次都会**新建一个站点**（新网址）。
> 更新必须拖到 **已有站点的 Deploys 页**。

> 注意：因为用了 `<script src>` 普通脚本而不是 ES Module，所以不挑托管平台，也不会触发 MIME/CORS 问题。

## 调试参数

在地址后追加：

```
?intro=0      跳过择道，直接以剑修开局
?nocg=1       跳过过场 CG（方便调试）
?tod=0.15     指定初始时辰（0=子夜，0.5=正午）
?debug=map        直接打开传送图志
?debug=menu       直接打开设置菜单
?debug=act        直接打开活动面板
?debug=talk       直接与玄清子对话
?debug=portraits  立绘一览（10 个角色）
```

想换地图地形，改 `js/data.js` 里 `MAPS` 各图的 `seed` 与 `band`（各海拔带阈值）即可。

浏览器控制台 `__qingyun` 暴露了 `G / player / loadMap / acceptQuest / castSkill / damageEnemy` 等，可直接调试。
